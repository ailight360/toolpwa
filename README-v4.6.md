# ToolPWA v4.6 — Growth & Quality Upgrade

Implemented the next product layer: genuinely useful new utilities, deeper tool-page content, anonymous aggregate usage analytics/trending, stronger internal discovery, Schema.org SoftwareApplication + BreadcrumbList + FAQPage, performance-friendly deferred JS, PWA install UX retained, and tool-specific examples/presets.

## New tools
Aspect Ratio Calculator, Roman Numeral Converter, Number Base Converter, CSV to JSON, JWT Decoder, HTML Entity Encoder, CSS Box Shadow Generator, Color Palette Generator, Markdown Table Generator, Text Statistics, Date Difference Calculator, Percentage Change Calculator.

## Analytics
Usage is aggregated by day and tool slug. No IP address, account ID, or tool input is stored. Browser localStorage prevents repeat counting from the same browser/tool/day. Data is retained for 90 days.

## SEO
Tool pages now expose SoftwareApplication, BreadcrumbList and FAQPage structured data where applicable, plus feature/use-case/example content.
